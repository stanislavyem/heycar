CarPal public icon files

Copy every file in this folder into your project's public/ directory.

Files:
- favicon.ico
- favicon-96x96.png
- favicon.svg
- apple-touch-icon.png
- site.webmanifest
- safari-pinned-tab.svg
- carpal-icon-master.png (1024px master artwork; optional)

The SVG favicon is self-contained and embeds the generated PNG artwork.
The Safari pinned-tab SVG is a separate monochrome car silhouette for Safari's mask-icon feature.
